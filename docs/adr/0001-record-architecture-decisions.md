# 1. Record architecture decisions

Date: 2026-11-23

## Status
Accepted

## Context
We need to record the architectural decisions made on this project so the reasoning stays visible to future contributors and to Claude across sessions.

## Decision
We will use Architecture Decision Records, as described by Michael Nygard. Files live in `docs/adr/`, are numbered sequentially (`NNNN-title.md`), and use the sections Status, Context, Decision, Consequences. Superseded ADRs are kept and marked as such.

## Consequences
Decisions are reviewable in Git history. Each significant change in direction needs a short ADR, which adds small overhead.
